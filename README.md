# Jackman Media — Roman Jackman Portfolio

Personal portfolio for Roman Jackman (Jackman Media) — sports & brand graphic design and video.

- **Live:** https://romanportfoliocurrent.netlify.app
- **Stack:** Vite + React + TypeScript + Tailwind CSS v4, `motion` for animation.
- **Deploy:** push to `main` → Netlify auto-builds (`npm run build`) and publishes `dist/`.

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```

Content lives in `src/data.ts`; UI in `src/components/`.
